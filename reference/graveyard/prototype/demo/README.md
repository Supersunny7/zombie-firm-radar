# Interactive look-dev demo (reference only)

Claude's interactive prototype of the graveyard horror direction: flashlight on the pointer, rate-shock slider,
three graves whose zombies rise with a keyframed bone sequence, a shambling walker, the hooded Watcher that vanishes in
the beam, CCTV grade as a ShaderPass, and Web Audio (wind, crows, growl, footsteps).
Never imported by app code. Values here and in `../../horror-direction-params.md` are the target look.
Asset names match `web/public/assets` (the hosted copy wraps each .glb in a base64 module only because the host does not serve .glb).
