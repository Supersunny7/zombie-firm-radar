# Reference images

Visual targets from the design prototypes made outside Kiro (Claude, November 2026). They are **reference only**: no code in this repository imports anything from `/reference`, and the prototype code is not part of the project. Exact starting values are in `.kiro/steering/scene-reference.md`.

| File | Shows | Match these qualities |
| --- | --- | --- |
| `graveyard/graveyard-rate-shock-3pp.png` | Graveyard at +3 pp rate shock, flashlight on a tombstone, hands rising | Near-black scene, single warm flashlight pool, cold moon rim light, low ground fog, CCTV grain and vignette, HUD never covering the stage |
| `lab/lab-default.png` | Lab default camera, patient on the table | Surgical lamp pool on the patient only, dark crypt walls, red emergency bulb accent, docked side and bottom panels |
| `lab/lab-failure.png` | Failure outcome | Red flood from the screen edges, hands reaching in, centre text still readable |
| `lab/lab-closeup.png` | Free camera pushed in on the body | Decay shader detail readable in close-up, no overexposure |

`progress/` holds screenshots taken by the scene-critic agent during development.
