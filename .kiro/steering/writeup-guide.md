# Writeup Guide

- The judges score how deeply and creatively we used Kiro. Every claim must point to evidence: a file in `.kiro/`, a commit, a screenshot in `docs/kiro-evidence/`, or a `DEVLOG.md` line.
- Answer the eight hackathon questions in this order:
  1. Kiro surfaces used (IDE, CLI, Web, Crew) and how they differed.
  2. Custom agents.
  3. Agent hooks.
  4. Spec-driven development vs vibe coding.
  5. Steering strategy.
  6. MCP.
  7. Property-based testing.
  8. Kiro powers.
- Plain, specific English. Numbers over adjectives (tests, properties, bugs caught, credits used).
- State that the `/reference` prototypes were design explorations made outside Kiro, that documentation help came from Claude, and that all application code and `.kiro` configuration were built with Kiro.
